# Nico the Little Reindeer: AI Studio prompts (32 inside pictures)

Plan: set up AI Studio once, paste ONE text into the System instructions box, then paste 32 short messages, ONE picture per message. Save each picture right away. Do 8 pictures per chat (4 chats).

## 1. Settings (aistudio.google.com, open a Chat; on a phone tap the sliders icon)

- Model: Nano Banana Pro (Gemini 3 Pro Image). If it is not listed or you run out of quota: Nano Banana 2, then Nano Banana.
- Aspect ratio: 1:1
- Image size: 2K (use 4K only if 2K works perfectly; no size choice on the oldest model is normal)
- Temperature: leave at the default (1)
- Output format: Images (and text) is fine; "Images only" is fine too
- Google Search grounding: OFF. Code execution: OFF.
- Thinking: leave at the default.

## 2. Paste ONCE into the "System instructions" box (paste it again in each new chat)

```
You draw pages for a children's coloring book (ages 3 to 6), "Nico the Little Reindeer's Snowy Day".
Every message I send is ONE picture ("Picture 7: ..."). Make exactly ONE new image with only that picture. Never a collage, grid, panels or sheet. Reply with the image only. Do not ask questions.

Look of every image: black and white coloring-book line art only. Very thick, clean, bold black outlines, all the same weight. Big simple shapes, cute kawaii style, few small details. Pure white background and white inside every shape. NO gray, NO shading, NO color, NO hatching, NO filled black areas except small eyes. NO text, letters, numbers, signs, border or frame. Square, the drawing fills the square. Snow is drawn as simple round snowflakes and a few soft bumps.
If a message says "top third open sky", keep the top third almost empty (a few simple clouds and snowflakes). If it says "bottom third calm", keep the bottom third simple, nothing small or busy.

Characters, always exactly the same:
- Nico: chubby baby reindeer, round head, two tiny branched antlers, small round ears, big round shiny eyes, tiny smile, round tummy, small fluffy tail. He wears his big fluffy red scarf ONLY when the message says "Scarf on". Draw the scarf as a line-art outline. Otherwise no scarf, no clothes.
- Tilly: cute round little penguin, small wings, tiny beak, knitted bobble hat (always worn).
- Mama Reindeer: a bigger Nico wearing an apron.
- Willow: shy little spotted fawn, white spots on her back, big eyes, no antlers.
```

## 3. One-minute test (first message of chat 1)

```
Picture 0: Nico standing and waving in the snow. Scarf on.
```

Good = ONE square, only black lines on white, no text, no gray. If you get color, gray, text or a chatty reply, the box was ignored: paste the section 2 text as your FIRST MESSAGE instead (add the line "Reply only: OK.") and do that in every new chat. Picture 0 is not used in the book.

## 4. How to work (phone)

- Paste one picture message, wait, look, save (long-press the image, or the download button; do not screenshot). Then the next.
- Chat 1 = pictures 1-8, chat 2 = 9-16, chat 3 = 17-24, chat 4 = 25-32. Start the next chat early if things get slow or drift.
- Keeping the same characters: in chats 2, 3 and 4, before the first picture, attach (+ button) your best Nico picture and best Tilly picture (plus Willow and Mama in the chats that need them) and send:

```
These are the official Nico, Tilly, Willow and Mama Reindeer. Draw them exactly like this in every picture from now on. Reply only: OK.
```

## 6. Recovery messages (send in the same chat right after the bad picture)

Collage / several pictures in one:
```
Wrong. That is several pictures in one. Make ONE single full-square image with only this one picture. Same scene.
```
Gray, shading or color:
```
Redo the same picture in pure black outlines on pure white only. No gray, no shading, no color, no filled areas. Change nothing else.
```
Character looks different:
```
Nico (or Tilly / Willow / Mama) must look exactly like the official one I attached: same round head, tiny branched antlers, round ears, big shiny eyes, round tummy. Redo the same scene with the right character.
```
Missing scene (paste that scene's message again after it):
```
You skipped one. Make this picture now, as its own single image:
```
Something missing in the picture:
```
Something is missing: [name it, for example "Tilly the penguin" or "the teddy bear"]. Add it. Keep everything else the same.
```
Text, letters or numbers in the image:
```
Redo the same picture with no text, no letters, no numbers, no signs at all.
```
Border or frame:
```
Remove the border. The drawing goes to the edge on pure white, no frame. Change nothing else.
```
Scarf wrong (choose YES or NO):
```
Redo the same picture. Nico wears the red scarf: [YES / NO].
```
Top or bottom third not respected:
```
Keep the top third empty sky (only a few clouds and snowflakes). Move the drawing lower. Same characters.
```
(For the name page say: "Keep the bottom third calm: only the blanket and bed, nothing small or busy.")

Too busy:
```
Redo it simpler: fewer small details, bigger shapes, thicker lines, more white space.
```
Answer with words only, no image:
```
Just draw the image now, no text.
```
Not square:
```
Redo it as a perfect 1:1 square with everything fully visible.
```
If nothing helps: press Run/regenerate on the same message (each try differs), or start a new chat and repeat step 4.

## 7. Not verified (I could not test any of this in live AI Studio)

- The System instructions box may be missing or ignored for image models (test in step 3; fallback given).
- Exact model names and settings labels may differ on your screen today; Google's own docs pages were not readable for me.
- Line art often has faint gray edges or fills; expect to redo about 3 to 6 pictures for gray, collage or drifted characters.
- Nico, Tilly's hat and Willow's spots drift most; Willow and Mama appear rarely. Top/bottom-third rules are followed only loosely.
- Pro quota or billing limits may stop you; switching model changes the style a little, so redo the step 4 reference.
- Exact pixel size at 2K was not confirmed: check the saved file. Red cannot show in black and white, so the scarf is only an outline.
- Saving 32 pictures one by one on a phone is manual work.
