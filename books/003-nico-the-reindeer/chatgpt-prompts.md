# ChatGPT prompts for "Nico the Little Reindeer’s Snowy Day"

How to use: open ONE new ChatGPT chat and stay in it. Send Prompt 1, wait until all its images are done, download them, then send Prompt 2, and so on. If you ever have to start a new chat, upload one of the Nico pictures first and say "This is Nico, keep him exactly like this." Send the finished pictures to Claude in a chat message, a few zips at a time, after everything is done. No need to name or sort them: Claude matches every picture to its page.

If ChatGPT slips into a grid or cuts up an image, send: `Stop. That is wrong. Do not combine pictures and do not crop with code. Generate IMAGE [number] again as its own single, new, full-resolution image, then continue with the next image the same way.`
