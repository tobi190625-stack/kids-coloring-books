Send Prompt 1, wait until all 8 images are done and download them, then send Prompt 2, and so on (4 prompts, 8 images each = 32 pictures: title page, name page, 29 story pages, The End page). If you ever have to start a new chat, upload one of the Posy pictures first and say "This is Posy, keep her exactly like this." ```

```

```
