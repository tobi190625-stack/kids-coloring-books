# Tools and plugins to set up at home (NOT installed yet)

Ask the owner before installing anything. Only install from official sources. Never paste passwords or account keys
into a chat. Prices and free limits change: check them before signing up. Must-have = big gain for little effort.

## Must-have
| Tool | What it gives us | Notes |
|---|---|---|
| **Claude in Chrome** (extension) + Claude desktop app | Claude can look at TikTok Studio, YouTube Studio, Meta, Pinterest, KDP, Linktree in the browser: check posts, read stats, find problems | Owner stays logged in; Claude asks before clicking anything that changes or posts |
| **Metricool** (or Buffer / Later) | One place to schedule AND see stats for TikTok, IG, FB, YouTube, Pinterest; CSV export for the dashboard | Fixes the scheduling mess; check the free tier limits |
| **Amazon Attribution** (Amazon Ads console) | Tracking links per platform → which platform sells books | Needs the KDP account owner; check it's available for the account |
| **Obsidian** + Obsidian Git + Dataview | Second brain on top of this repo (see OBSIDIAN.md) | Free |

## Ad-making (make Claude better at creatives)
| Tool | What it gives us |
|---|---|
| **vidIQ MCP** (already connected in cloud sessions) | Competitor/outlier videos, trends, keyword research, our channel stats, Instagram reels data |
| **faster-whisper** (Python, local) | Speech-to-text for any video: transcribe competitor/saved reels to study hooks and scripts |
| **yt-dlp** | Download our own videos or public examples for frame-by-frame analysis (respect platform rules) |
| **Remotion** (React video framework) or **HyperFrames** skill (`npx skills add heygen-com/hyperframes`) | Videos as code with animations, templates and transitions; more polished than our Python renderer |
| **Kokoro TTS** (we use it) / better voice later (ElevenLabs etc., paid) | More natural voices; test if a better voice raises watch time |
| **Canva** (connector exists) | Quick pins, carousel variations, thumbnails |
| **ffmpeg** (have it) | Cutting, captions, formats |

## Research / Amazon
