# Fonts

**Grandstander ExtraBold** by Tyler Finck (Google Fonts), licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org). It is free to use in
commercial books; the font is embedded in the PDFs we upload to KDP.

Why this face: chunky and round like the Bold & Easy line art, and it has the
single-story "a" and "g" that children learn to write, which helps early readers.
